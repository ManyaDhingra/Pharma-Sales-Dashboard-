
# Pharmaceutical Sales Analytics Dashboard

## Project Overview
An interactive Pharmaceutical Sales Analytics Dashboard developed using Microsoft Power BI to analyse pharmaceutical sales, regional performance, medicine categories and inventory trends.

## Objectives
- Analyse pharmaceutical sales performance.
- Identify revenue trends across months and regions.
- Compare medicine and category performance.
- Monitor inventory and stock levels.
- Build an interactive dashboard using Power BI.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
Global Pharmacy Sales Dataset (2020–2025).

The dataset contains daily sales records with 14 columns covering date, geography, medicine, category, customer age group, units sold, pricing and inventory information.

## Data Cleaning & Transformation
- Removed duplicate records.
- Checked missing values and data quality.
- Created a Revenue column.
- Extracted Month Name and Quarter.
- Prepared data for analysis.

## Dashboard Features
- Total Revenue
- Total Units Sold
- Total Transactions
- Average Selling Price
- Monthly Revenue Trends
- Revenue by Region
- Revenue by Medicine
- Revenue by Category
- Inventory Analysis
